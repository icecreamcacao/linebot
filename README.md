# LINE 글자 수 집계 봇

LINE에서 들어온 텍스트 메시지의 길이를 사용자별로 누적하는 웹훅 코드입니다.

## 처리 흐름

1. POST 요청의 이벤트 목록에서 텍스트 메시지를 찾습니다.
2. 메시지를 보낸 사용자와 한국 표준시 기준 날짜를 확인합니다.
3. 날짜가 달라지면 해당 사용자의 누계를 새로 시작합니다.
4. 메시지 길이를 누계에 더하고, 집계 조회 문구가 들어오면 당일 누계 응답을 시도합니다.

## 코드 살펴보기

- [index.js](./index.js) · 웹훅 처리와 메모리 집계
- [package.json](./package.json) · LINE SDK, Express, 환경 변수 로딩 의존성

현재 집계는 프로세스 메모리에 있으므로 서버를 재시작하면 기록이 초기화됩니다. 배포 전에 의존성 선언, LINE 웹훅 요청 검증, 날짜 경계와 응답 동작을 확인해야 합니다.

## 다음 작업

- 한국 표준시 자정에 누계가 바뀌는지 검증합니다.
- 메시지 수신과 집계 로직을 분리해 LINE 없이도 테스트할 수 있게 합니다.
